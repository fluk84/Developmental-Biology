# ชีววิทยาพัฒนาการ: กระบวนการและกลไก
### Interactive Developmental Biology & Embryology Learning Platform

แพลตฟอร์มการเรียนรู้และวิจัยชีววิทยาพัฒนาการ (Developmental Biology) และคัพภวิทยา (Embryology) แบบปฏิสัมพันธ์ ขับเคลื่อนด้วยโมเดลปัญญาประดิษฐ์ Google Gemini พร้อมระบบการสืบค้นข้อมูลเชิงวิชาการแบบ Search Grounding

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. ภาพรวมและบทเรียนพื้นฐาน (Syllabus & Textbook Overview)
- สรุป 4 เสาหลักของชีววิทยาพัฒนาการ: กระบวนการระดับเซลล์, ชั้นเนื้อเยื่อและการสร้างอวัยวะ, การควบคุมระดับโมเลกุล, และการประยุกต์ทางการแพทย์
- แผนผังบทเรียนและสารบัญมาตรฐานระดับอุดมศึกษาและหลักสูตรแพทยศาสตร์
- บทคัดย่อเชิงวิทยาศาสตร์พร้อมระบบตรวจจับและไฮไลท์คำศัพท์อัตโนมัติ

### 2. เส้นเวลาจำลองการเจริญของตัวอ่อน (Embryonic Stages Timeline)
- สำรวจ 6 ระยะสำคัญ: ปฏิสนธิ (Fertilization), การแบ่งเซลล์แบบคลีเวจและโมรูลา (Cleavage & Morula), บลาสโทซิสต์และการฝังตัว (Blastocyst & Implantation), แกสตรูเลชัน (Gastrulation), นิวรูเลชัน (Neurulation) และระยะการสร้างอวัยวะ (Organogenesis & Fetal Period)
- แผนภาพ Morphogenesis แบบ SVG อินเทอร์แอคทีฟ ปรับตามระยะที่เลือก
- แสดงเหตุการณ์หลัก (Key Events) และโมเลกุลชักนำ (Molecular Drivers) ประจำแต่ละระยะ

### 3. แผนผังชั้นเนื้อเยื่อและอวัยวะ (Germ Layers & Organogenesis Map)
- เจาะลึกการเจริญของเนื้อเยื่อทั้ง 3 ชั้น: เอ็กโทเดิร์ม (Ectoderm), มีโซเดิร์ม (Mesoderm) และเอนโดเดิร์ม (Endoderm)
- แคตตาล็อกอวัยวะที่พัฒนามาจากแต่ละชั้น พร้อมระบบค้นหาอวัยวะแบบเรียลไทม์
- ระบุสัญญาณโมเลกุลควบคุมหลัก (Signaling Molecules) ประจำแต่ละชั้นเนื้อเยื่อ

### 4. แบบจำลองศักยภาพและการกำหนดชะตากรรมเซลล์ (Cell Fate & Potency Simulator)
- จำลองภูมิทัศน์เอพิเจเนติกส์ตามแนวคิดของ Waddington (Waddington's Epigenetic Landscape)
- ทดลองเปรียบเทียบระดับความสามารถของเซลล์: Totipotent, Pluripotent, Multipotent, และ Unipotent
- แสดงยีนควบคุม (Master Transcription Factors) และลูกศรชี้นำวิถีการเจริญของเซลล์

### 5. การควบคุมระดับโมเลกุลและพันธุกรรม (Molecular & Genetic Regulation)
- การแสดงออกของยีนที่แตกต่างกัน (Differential Gene Expression) ในมิติเวลาและพื้นที่ (Spatiotemporal Regulation)
- เจาะลึก 5 วิถีส่งสัญญาณหลักในตัวอ่อน:
  - **SHH (Sonic Hedgehog)**: การกำหนดแกนซ้าย-ขวา ลำตัว และสมองส่วนหน้า
  - **WNT / β-catenin**: การแบ่งขั้วตัวอ่อนและการเคลื่อนที่ของเซลล์
  - **BMP / TGF-β**: การกำหนดแกนหลัง-ท้อง (Dorsoventral) และชะตากรรมกระดูก/ไต
  - **FGF / RTK**: การแบ่งตัว การยืดตัวของลำตัว และการเกิดตุ่มรยางค์
  - **Notch / Delta**: กลไก Lateral Inhibition และการจัดเรียงปล้องโซไมต์ (Somitogenesis)
- รายละเอียด Ligands, Receptors, โมเลกุลภายในเซลล์, ยีนเป้าหมาย และความสำคัญทางพยาธิสภาพ

### 6. การประยุกต์ใช้ทางการแพทย์และเวชศาสตร์ฟื้นฟู (Clinical & Regenerative Medicine)
- 3 นวัตกรรมชีวการแพทย์: เซลล์ต้นกำเนิด iPSCs (Yamanaka Factors), เทคโนโลยีออร์แกนอยด์ 3 มิติ (Organoids), และพิษวิทยาต่อตัวอ่อน (Teratology)
- กรณีศึกษาพยาธิกำเนิดแต่กำเนิด (Congenital Defects):
  - Spina Bifida (ความผิดปกติของการปิดท่อประสาท)
  - Cleft Lip & Palate (ปากแหว่งเพดานโหว่)
  - Holoprosencephaly (ความผิดปกติของ Shh ในการแบ่งสมองส่วนหน้า)
  - Hirschsprung Disease (เซลล์สันประสาทเคลื่อนที่ผิดปกติในลำไส้)

### 7. คลังคำศัพท์ชีววิทยาเชิงโต้ตอบ (Interactive Glossary & Search Grounding)
- **Hover & Click Popovers (`GlossaryPopover`)**: วางเมาส์หรือคลิกคำศัพท์เทคนิค เช่น *Gastrulation*, *Apoptosis*, *Cleavage*, *Pluripotent*, *Sonic Hedgehog*, *Neural Crest* เพื่อดูความหมาย กลไก และคำศัพท์ที่เกี่ยวข้องทันที
- **Contextual Text Highlighting (`GlossaryText`)**: ตรวจจับคำศัพท์ทางวิทยาศาสตร์ในข้อความอัตโนมัติและแสดงเป็นปุ่มกดป๊อปโอเวอร์โดยไม่ทำให้ข้อความสะดุด
- **Google Search Grounding**: ปุ่มดึงข้อมูลวิจัยล่าสุดและเอกสารอ้างอิงผ่าน Gemini 2.5 Flash ร่วมกับเครื่องมือ `googleSearch`
- **Glossary Browser Modal**: ค้นหาและกรองคำศัพท์ตามหมวดหมู่ได้ครอบคลุมทั้งระบบ

### 8. ผู้ช่วยชีววิทยา AI และเครื่องมือเสริม (AI Tutor & Multimodal Tools)
- **Chat Assistant**: ผู้ช่วยสนทนาตอบคำถามเชิงลึกเกี่ยวกับชีววิทยาพัฒนาการ พร้อมหัวข้อสนทนาแนะนำและระบบสังเคราะห์เสียงพูด
- **Embryo Image Analyzer**: อัปโหลดหรือลากวางภาพสไลด์จุลกายวิภาค (Histology) หรือภาพตัวอ่อน เพื่อให้ AI ตรวจสอบระยะ ลักษณะสัณฐานวิทยา และโครงสร้างที่พบ
- **Diagram Generator**: สร้างแผนภาพโครงสร้าง วิถีส่งสัญญาณ หรือผังลำดับเหตุการณ์การพัฒนาการผ่าน AI
- **Interactive Quiz**: แบบทดสอบวัดความเข้าใจพร้อมเฉลยแบบละเอียดและคำอธิบายโดย AI

### 9. โหมดการอ่านและส่งออก PDF สำหรับการศึกษาออฟไลน์ (Offline Study & PDF Export)
- สลับเข้าสู่ **Print-Friendly Study Mode** ด้วยคลิกเดียว เพื่อปรับรูปแบบสี คอนทราสต์ และฟอนต์ให้อ่านง่ายบนกระดาษ
- ส่งออกบทเรียนปัจจุบันหรือเนื้อหาทั้งหมดเป็นไฟล์เอกสาร PDF พร้อมระบบจำแนกหน้าอัตโนมัติ

## 🛠️ สถาปัตยกรรมและเทคโนโลยี (Tech Stack)

- **Frontend**:
  - React 19 + TypeScript
  - Tailwind CSS v4
  - Lucide React (ไอคอน)
  - Motion (แอนิเมชัน)
  - html2canvas & jsPDF (การเรนเดอร์และสร้างไฟล์ PDF)
  - Canvas Confetti (เอฟเฟกต์ประเมินผลคะแนน)
- **Backend & Middleware**:
  - Node.js + Express (API Routes & Development Server)
  - tsx (TypeScript runtime development execution)
  - esbuild (Production backend bundling)
- **AI Integration**:
  - Google Gen AI SDK (`@google/genai`)
  - Gemini Models: `gemini-2.5-flash` สำหรับการวิเคราะห์ภาพ การแชท และการสร้างแบบทดสอบ
  - Search Grounding (`googleSearch`) ผ่าน Endpoint `/api/gemini/glossary-lookup`

## 🚀 การติดตั้งและเริ่มใช้งาน (Getting Started)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- Node.js (เวอร์ชัน 18 ขึ้นไป)
- บัญชี Google AI Studio สำหรับรับ `GEMINI_API_KEY`

### 1. ติดตั้งแพ็กเกจ (Install Dependencies)
```bash
npm install
```

### 2. กำหนดค่าตัวแปรสภาพแวดล้อม (Environment Variables)
คัดลอกไฟล์ `.env.example` ไปเป็น `.env` และกรอก API Key:
```bash
cp .env.example .env
```
กำหนดค่า:
```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY_HERE"
```

### 3. เริ่มเซิร์ฟเวอร์สำหรับการพัฒนา (Start Development Server)
```bash
npm run dev
```
แอปพลิเคชันจะเปิดทำงานที่ `http://localhost:3000`

### 4. การตรวจสอบไวยากรณ์และคอมไพล์สำหรับ Production (Build & Start)
```bash
# ตรวจสอบประเภทข้อมูล TypeScript
npm run lint

# บิลด์ทั้งส่วน Client (Vite) และ Server (esbuild)
npm run build

# สตาร์ตเซิร์ฟเวอร์แบบ Production
npm start
```
